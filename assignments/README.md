# 📝 Solo Assignments — your exam, on real Kaggle data

These are the playbook's **solo assignments**. They are deliberately **not built** in this repo — you build them, on the **original Kaggle datasets**, to prove the guided projects' skills transferred.

Each file poses the framing questions **without answers** plus the playbook's requirement checklist. Answer every question in writing *before* you code.

## How to use

1. Finish the matching guided project first (SCENARIO → BUILD_GUIDE → reference → EXPLANATION).
2. Download the real Kaggle dataset listed below.
3. Open the assignment questions file and answer everything on paper.
4. Build with no guide. Self-check against the requirement list at the bottom of each file.
