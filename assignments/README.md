# 📝 Solo Assignments — Framing Questions

These are the **solo assignments** from the playbook. They are deliberately **not built** in this repo — you build them, to prove you internalized the guided projects.

Each file here poses **framing questions with no answers** — the same kind of questions the guided-project `QUESTIONS.md` files answer, but left open for *you* to answer while building. Use them as a checklist/scaffold, not a solution.

## How to use these

For each assignment:
1. **Read** the guided project it mirrors, in order: `QUESTIONS.md` → `README.md` → `EXPLANATION.md`.
2. **Open** the matching assignment questions file below and answer every question **in writing** before you code.
3. **Build** the assignment on a fresh dataset. Let your written answers drive the design.
4. **Check** yourself against the playbook's requirement list (restated at the bottom of each file).

> The point is transfer: same concepts, new dataset, no hand-holding. If you can answer the framing questions cold, the code follows.
